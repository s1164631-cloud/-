# WS2812B 灯带射击消消乐（T5-E1）

## 接线

| 功能 | 引脚 |
|------|------|
| 灯带 DIN | **P4**（SPI1 MOSI） |
| 红键 | **P44** |
| 绿键 | **P45** |
| 蓝键 | **P46** |

灯带需 5V 供电并与开发板共地。默认长度 **150** 灯珠（可调 150–300，步长 30）。

## 分区

| LED | 作用 |
|-----|------|
| 0–2 | 火焰区（玩家基地，不参与碰撞；显示生命） |
| 3–N-1 | 游戏区：块从顶部下落，子弹从底部向上 |

## 操作

- **短按** 红/绿/蓝：发射同色子弹
- **结束后任意短按**：重开
- **结束后长按**：切换灯带长度 150→180→…→300→150
- **局内长按**：重开本局

## 规则摘要

- 同色命中：`score += 10 × combo`，连击累加；每 3 次有效连击 `health_count++`
- 异色命中 / 漏块进火焰：`lives--`，连击清零；连续 miss≥2 触发彩虹涟漪
- 连击到 4：技能充能；第 5 次命中触发技能（粉弹清场 + 速度翻倍，每局一次）
- 粉弹命中任意色：`+20` 分，不改连击
- 胜利：`health_count` 铺满整条灯带（全绿）
- 失败：`lives == 0`
- 等级：`level = score/100 + 1`（上限 10），速度表见源码
